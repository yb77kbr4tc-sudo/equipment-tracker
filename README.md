# Equipment Tracker

A mobile-first equipment tracking system for construction sites and field operations.

## Features

- 📱 **Mobile & PWA** - Install as an app on your phone
- 🔧 **Equipment Management** - Track tools, machinery, and assets
- ✅ **Check In/Out** - Assign equipment to workers and sites
- ⏰ **Due Return Tracking** - Monitor overdue and upcoming returns
- 📊 **Dashboard** - Real-time inventory overview
- 🔍 **Search & Filter** - Find equipment by status, name, serial number
- 📴 **Offline Support** - Works without internet connection (localStorage)

## Getting Started

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Technology Stack

- **React 18** - UI framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **localStorage** - Data persistence
